# 🚀 Trading App

## 📌 Project Overview

Developed a **full-stack trading dashboard** inspired by real-world platforms like Zerodha, focusing on **fintech application design, user experience, and data-driven insights**.  

The platform enables users to simulate stock trading activities with an **interactive, responsive, and intuitive UI**.

---

## 🔧 Tech Stack
- **Frontend:** React.js, JavaScript, HTML5, CSS3  
- **UI/UX:** Material UI, Responsive Design, Flexbox  
- **Data Visualization:** Chart.js  
- **State Management:** React Hooks (useState, useContext)  
- **Routing:** React Router  
- **Version Control:** Git & GitHub  

---

## ✨ Key Features

### 📊 Trading Dashboard
- Designed a **Zerodha-inspired UI** with responsive layout  
- Built **modular and reusable React components**

### 📈 Data Visualization
- Integrated **Chart.js** for:
  - Stock trends  
  - Portfolio performance  
  - Trading analytics  
- Enabled **dynamic updates based on user interaction**

### 💰 Buy/Sell Functionality

- Implemented **interactive Buy/Sell actions**
- Simulated trading behavior with real-time UI updates  

### 📂 Portfolio Management
- Developed **Holdings and Positions modules**
- Calculated:
  - Profit & Loss (P&L)  
  - Net change  
  - Day change  
- Applied **conditional styling for profit/loss indicators**

### 🔍 Watchlist System
- Built a **dynamic stock watchlist**
- Features include:
  - Hover-based action buttons  
  - Real-time stock indicators (up/down trends)  
  - Clean UI interactions  

### 🎯 UI/UX Enhancements
- Smooth hover effects and dropdown interactions  
- Responsive layout using **flexbox and percentage-based design**  
- Focused on **minimal and user-friendly fintech UI principles**

---

## 🧠 Core Concepts Applied
- Component-based architecture (React)
- State management using hooks
- Conditional rendering and dynamic styling
- Event handling and user interaction design
- Scalable and modular frontend structure
